# Security and responsible use

SpiderCore PE is intended for authorized recovery, maintenance, digital-forensics, and incident-response work. Only use it on computers, storage media, accounts, and networks that you own or have explicit permission to examine.

The toolkit includes powerful utilities for disk editing, credential recovery, file recovery, remote support, encryption, and malware scanning. These capabilities can cause permanent data loss or expose sensitive information if used carelessly.

Recommended workflow:

1. Preserve the original media where possible and work from a verified image or clone.
2. Record the device, date, operator, and actions taken.
3. Verify checksums and keep backups before destructive operations.
4. Test unfamiliar tools in a disposable virtual machine.
5. Disconnect or restrict networking when offline analysis is more appropriate.
6. Do not use password-reset, remote-access, or credential tools to bypass authorization.

Security issues in the SpiderCore PE documentation or original branding can be reported to the project maintainer through the `rajatayyabb` GitHub account. Third-party binaries should be reported to their respective vendors.
